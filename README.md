# Temeraire Foundry VTT System

A Foundry VTT game system for the **Temeraire** tabletop RPG.  Please note that at present the full release of the game is not available to the public, so this Foundry system is based **only on the Quickstart document**.  It will be updated as necessary for the full release.

## Features

### Game System
- Separate character sheets for **dragon players**, **human players**, and **NPCs**
- Sheets for all item types that may apply to PCs
- Click on attribute/skill names to initiate challenge rolls; available modifiers are calculated and listed for player to choose, and roll is automated with ability to spend devotions to modify the results.

## System Compatibility

- **Minimum Foundry Version:** v14
- **Verified Version:** v14

## Installation

1. In Foundry VTT, navigate to the Systems browser
2. Search for "Temeraire" and install
3. Create a new world using the Temeraire system


## Development

- For those who might care about such things, this system is built using Foundry's Appv2 API to allow for native pop-out windows and future compatibility.
